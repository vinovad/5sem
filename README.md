# Платформа дистанционного обучения (ЛР №2)

Реализация объектной модели из ЛР №1. Python 3.10+, интерфейс на Tkinter, данные в SQLite.
Внешних зависимостей нет.

## Запуск

    python main.py

При первом запуске создаётся файл `app.db` с тестовыми данными (3 курса, вебинар).
Чтобы сбросить данные, удалите `app.db`.

## Вход

Тестовые аккаунты (пароль у всех `1234`):

| Email              | Роль          | Открывается          |
|--------------------|---------------|----------------------|
| student@gmail.com  | Учащийся      | Главное окно         |
| prepod@gmail.com   | Преподаватель | Панель преподавателя |
| admin@gmail.com    | Администратор | Ошибка (окна нет в модели) |

Новый учащийся создаётся кнопкой «Создать аккаунт» (логин и пароль берутся из формы входа).
Если вы запускали более раннюю версию, удалите `app.db`, чтобы данные создались заново.

## Структура

- `main.py`: `MainApplication` (`<<main, injector>>`)
- `models/`: `<<data>>`-классы
- `services/`: 5 сервисов (`mappers.py` служебный)
- `ui/`: `MainUi` и окна по макетам (`theme.py` и `helpers.py` служебные)
- `db/`: подключение к SQLite, схема, тестовые данные
- `test.py`: покрытие тестами
Элементы, при нажатии на которые появляется сообщение «Недоступно в модели», соответствуют местам, где модель не позволяет реализовать
функцию. Все такие места описаны в `PROBLEMS.md`.
